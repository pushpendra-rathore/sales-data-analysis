# Sales Data Analysis (Excel)
 
An Excel-based analysis of sales data to track performance by region, salesperson, and product category.
 
## Dataset
- Order ID, order date, customer name, salesperson
- Region and state
- Product category and product details
 
## Tools Used
- Microsoft Excel / Google Sheets
- Pivot tables, formulas, charts
 
## What's Inside
- **sales-data** sheet: cleaned raw data
- **KPI Dashboard**: key metrics at a glance
- **Sales Dashboard**: sales by region, salesperson and category
