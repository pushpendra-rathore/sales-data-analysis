# Sales Data Analysis (Excel / Google Sheets)
 
Analysis of 30 sales orders (Jan-May 2026) to understand performance by region, product category, salesperson, customer type and payment mode.
 
## Tools Used
Google Sheets / Excel: formulas, pivot-style summary tables, KPI & Sales dashboards
 
## Project Structure
- **sales-data**: raw order data
- **KPI Dashboard**: key metrics and summary tables
- **Sales Dashboard**: charts and visuals
 
## Key Metrics
| Metric | Value |
|---|---|
| Total Sales | 454,090 |
| Total Profit | 126,390 |
| Profit Margin | 27.7% |
| Units Sold | 107 |
| Total Discount | 43,790 |
 
## Key Insights
- **West** is the top region with 166,640 in sales (about 37% of total), followed by North and East.
- **Electronics** drives half the revenue (231,241, ~51%) and has the highest profit (63,741).
- **Pooja** is the top salesperson (159,180 sales, 38,480 profit) with only 7 orders, so she closes high-value deals.
- **March** was the best month (120,936 sales, 32,136 profit).
- **Existing customers** contributed about 62% of sales (283,715) from the same number of orders as new customers.
- **Card** payments brought the most sales (150,163); **UPI** had the most orders (10).
